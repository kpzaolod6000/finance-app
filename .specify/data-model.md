# Data Model — PostgreSQL

Database schema. Every table is created via migration. PKs use UUID v7 (time-ordered). Money in
`numeric(14,2)`. Dates in UTC. Soft deletes where applicable. Version 1.0.

---

## Relationship diagram (summary)

```
users ─┬─< accounts ─────< transactions >───── categories
       ├─< categories
       ├─< budgets >──── categories
       └─< recurring_transactions >── accounts, categories

transactions.transfer_account_id ──► accounts   (only when type = 'transfer')
categories.parent_id ──► categories              (subcategories, one level)
```

`>` and `<` mark the "many" side. A line = a foreign key.

### transactions
The core.

| Column | Type | Notes |
|--------|------|-------|
| id | uuid (pk) | |
| user_id | uuid (fk → users) | indexed |
| account_id | uuid (fk → accounts) | source account |
| transfer_account_id | uuid null (fk → accounts) | destination, only when type = transfer |
| category_id | uuid null (fk → categories) | null = uncategorized |
| type | varchar (enum TransactionType) | income, expense, transfer |
| amount | numeric(14,2) | always > 0 (CHECK) |
| currency | varchar(3) | |
| occurred_at | date | accounting date |
| description | varchar null | |
| recurring_transaction_id | uuid null (fk) | set if generated by a recurring template |
| created_at / updated_at | timestamptz | |
| deleted_at | timestamptz null | soft delete |

Indexes: `(user_id, occurred_at)`, `(account_id)`, `(category_id)`, `(type)`.
CHECK: `amount > 0`.
CHECK: if `type = 'transfer'` then `transfer_account_id IS NOT NULL AND transfer_account_id <> account_id`.

## Key integrity rules

1. Deleting an account with transactions → blocked (archive instead). FK `ON DELETE RESTRICT`.
2. Deleting a category with transactions → reassign or set `category_id = null`.
   FK `ON DELETE SET NULL`.
3. Every user FK → when a user is deleted, a controlled cascade of their data.
4. Soft delete on accounts, categories, transactions for auditing.
5. All amounts with CHECK `> 0`; the sign is determined by `type`, not by the value.
